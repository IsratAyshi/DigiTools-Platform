
# Digital Tools Marketplace
---
# Project Description
- Digital Tools Marketplace is a modern, responsive SaaS products subscription platform built with React, Tailwind CSS and Daisy UI. Users can browse through a curated collection of premium digital tools designed to boost productivity and creativity. The platform offers a smooth and intuitive user experience with real-time cart updates, toast notifications, and a clean, professional design following modern Figma standards. 
Whether it be AI writing tools, design assets, resume builders, content analytics tools, or a complete starter kit, Digital Tools Marketplace has everything covered.
---
## Technology used
- React.js + Vite
- Tailwind CSS, DaisyUI
- JavaScript (ES6+)
- React-Toastify (NPM Package)
- JSON Data

---
## Features
- Browse & Discover Products — Clean product grid with detailed product cards for easy navigation. 
- Add to Cart & Checkout — Add products to cart, view cart items and live cart item count, remove individual items from cart, see total price and finally proceed to checkout.
- Clean, consistent UI and smooth checkout flow with React Toastify alerts.
